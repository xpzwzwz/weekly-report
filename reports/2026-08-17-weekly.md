# 「具身智能 + 大模型」五路进展周报

**时间范围：2026-08-10—2026-08-17（北京时间；截至 08-17）**

## 第一路｜VLA / 遥操作 / 具身数据

### ✅ 已核实要点

- **2026-08-13｜X Square Robot 展示物流场景具身系统**：公司在新加坡仓储环境展示 Quanta X2、Wall-OSS 世界模型和自研 VLA 协同完成拣选、搬运与分拣；属于公司演示，尚无公开独立真机 benchmark，能力描述均标记为【自报】。[公司新闻稿](https://www.prnewswire.com/apac/news-releases/x-square-robot-demonstrates-embodied-ai-in-real-world-logistics-operations-302850581.html)
- **截至 2026-08-17｜其余重点厂商与研究方向**：未发现本周由官方博客、GitHub 或 arXiv 摘要页确认的新 VLA、遥操作/触觉系统、开源真机数据集或评测基准；**本周无更多可核实新动态**。

### ⚠️ 传闻

- **2026-08-17｜“宇树 Superman 超高速人形机器人”视频**：社区广泛转载，但未检索到宇树官方产品页、技术报告或可核验测试条件；速度和产品身份不纳入已核实进展。

### 本周最值得关注的 2–3 项

1. X Square 将世界模型、VLA 与移动操作平台放进同一物流演示链路。
2. 演示缺少第三方成功率、任务覆盖和连续运行数据，现阶段应按【自报】看待。
3. 本周 VLA 论文、遥操作与新数据集发布偏少，不用旧工作补位。

## 第二路｜多模态大模型

### ✅ 已核实要点

- **2026-08-14｜Qwen3.8-27B 官方权重开放**：Qwen 官方 Hugging Face 仓库上线 Apache-2.0 权重，模型类型为 `image-text-to-text`，支持图文输入；官方仓库元数据显示 08-14 完成发布更新。[官方模型卡](https://huggingface.co/Qwen/Qwen3.8-27B)
- **2026-08-10｜vLLM v0.27.0 扩展多模态执行能力**：新增 Qwen3.5 的 EVS 视频 token 剪枝、VidCom2 视频 token 剪枝、Gemma 4 ViT CUDA Graph、Cosmos3 FP8 映射和 DeepSeek-OCR-2 TTFT 优化；这些是推理实现，不代表对应模型本周首发。[GitHub Release](https://github.com/vllm-project/vllm/releases/tag/v0.27.0)
- **截至 2026-08-17｜OpenAI、Anthropic、Google DeepMind 等**：未发现本周新发布且有正式模型卡或官方技术页的通用多模态模型；**本周无更多可核实新动态**。

### ⚠️ 传闻

- 本周未发现值得单列、且有可信二手交叉信源的新多模态模型传闻。

### 本周最值得关注的 2–3 项

1. Qwen3.8-27B 将新一代 Qwen 多模态能力下放到可本地部署的 27B 规模。
2. 视频 token 剪枝和视觉编码 CUDA Graph 正成为 VLM 服务优化的常规能力。
3. 除 Qwen 权重开放外，本周头部实验室模型发布较少。

## 第三路｜部署 / 推理 Infra

### ✅ 已核实要点

- **2026-08-10｜vLLM v0.27.0 发布**：包含 561 个提交、242 位贡献者【自报】；完成 Kimi K3 全栈支持，并升级至 PyTorch 2.13、Triton 3.7.1，属于有兼容性影响的环境变更。[GitHub Release](https://github.com/vllm-project/vllm/releases/tag/v0.27.0)
- **2026-08-10｜vLLM 强化长上下文与分离式推理**：FlashAttention 4 在 SM100 增加 FP8 KV cache 和 head-dim 256；新增混合 MLA+SSM 模型的 NIXL P/D、异构 P/D block size、MoRIIO TP↔DP 路由，以及通用 P2P KV 二级缓存。[GitHub Release](https://github.com/vllm-project/vllm/releases/tag/v0.27.0)
- **2026-08-10｜vLLM 扩展大规模容错与服务前端**：加入 DP+EP 外部负载均衡部署的简化容错框架、弹性 EP 异步准备，并为 Rust 前端增加健康检查、终止请求、服务发现和 KV 事件源发现等 gRPC 控制面能力。[GitHub Release](https://github.com/vllm-project/vllm/releases/tag/v0.27.0)
- **2026-08-11｜vLLM v0.27.1 补丁版**：在 v0.27.0 上增加量化 DSpark Markov head 支持。[GitHub Release](https://github.com/vllm-project/vllm/releases/tag/v0.27.1)
- **2026-08-12｜TensorRT-LLM v1.3.0rc24**：加入 TriAttention KV-cache 压缩、FlashInfer block reuse、Kimi K3 模型与 KDA kernel、Cosmos3 V2V、Qwen-Image TeaCache/Cache-DiT 等；官方同时列出 `torch.compile`+CUDA Graph、SM120 MLA+MTP 等已知崩溃风险。[GitHub Release](https://github.com/NVIDIA/TensorRT-LLM/releases/tag/v1.3.0rc24)

### ⚠️ 传闻

- 本周无值得单列的推理基础设施传闻。

### 本周最值得关注的 2–3 项

1. vLLM 0.27.0 同时推进混合模型 P/D、KV 分层和弹性 EP，重点明显转向超大模型集群服务。
2. Rust 前端开始具备独立控制面能力，不再只是请求入口实验。
3. TensorRT-LLM rc24 功能密集，但官方已知问题意味着生产升级应先做回归测试。

## 第四路｜轻量化 / 模型压缩

### ✅ 已核实要点

- **截至 2026-08-17｜本周无可核实新动态**：未发现本周首次发布、并可由 arXiv 摘要页或官方项目确认的新量化、剪枝、蒸馏、低秩分解或权重稀疏化方法。
- **边界说明**：vLLM/TensorRT-LLM 新增的 FP4、FP8、KV-cache 压缩和量化 kernel 属于系统执行支持，已归第三路，不重复视作新的模型压缩算法。

### ⚠️ 传闻

- **2026-08-17｜TensorShrink 社区项目**：作者声称其 2/4/6/8-bit 量化在速度和内存上优于 bitsandbytes，但目前主要证据来自社区自荐，缺少论文与独立复现，暂不列入已核实要点。

### 本周最值得关注的 2–3 项

1. 本周没有足够可靠的新压缩算法发布。
2. 工程侧低精度支持继续扩张，但需与“提出新压缩方法”严格区分。
3. TensorShrink 可观察后续 benchmark、模型覆盖和第三方复现。

## 第五路｜训练进展

### ✅ 已核实要点

- **截至 2026-08-17｜训练方法本周无可核实新动态**：未发现本周由 arXiv 摘要页或官方技术报告确认的新 RLHF、DPO、GRPO/RLVR、优化器、数据配比、scaling law 或 MoE 训练方法。
- **截至 2026-08-17｜训练系统本周无可核实新动态**：未发现本周正式发布的 FSDP、Megatron、DeepSpeed、ZeRO、3D 并行、显存或训练通信优化重大版本。
- **边界说明**：vLLM v0.27.0 的 RL rollout 权重版本标签、trainer-send IPC 和权重重载支持属于推理/rollout 基础设施，已归第三路，不作为新训练算法重复收录。[GitHub Release](https://github.com/vllm-project/vllm/releases/tag/v0.27.0)

### ⚠️ 传闻

- 本周无值得单列的训练方法或训练系统传闻。

### 本周最值得关注的 2–3 项

1. 本周训练侧缺少可核实的新方法或重大系统版本。
2. 推理框架正在补齐 RL rollout 接口，但这不等于新的后训练算法。
3. 保持空缺比重复收录此前发布的 FeynRL、Miles、verl 等框架更新更可靠。
