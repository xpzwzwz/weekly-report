# 「具身智能 + 大模型」五路进展周报

**时间范围：2026-08-10—2026-08-17（北京时间；截至 08-17）**

> 边界说明：DFlash2 的 Hugging Face 仓库虽于 08-15 预创建，但官方博客与正式发布均为 **08-18**，因此不计入本期，归入下一期。

## 第一路｜VLA / 遥操作 / 具身数据

### ✅ 已核实要点

- **2026-08-17｜τ₀-VLA：世界模型引导的测试时计算**：层级 VLA 在高层子任务生成时搜索候选，再由低层策略跨机器人本体执行；论文称以 40,115 小时异构真机数据训练【自报】。[arXiv:2608.16885](https://arxiv.org/abs/2608.16885)
- **2026-08-17｜ViHaTeleop：低成本视觉—触觉遥操作**：0.7 kg、约 550 美元的腕部 SLAM + 手部视觉跟踪 + 分指振动反馈系统；9 人 6 项接触任务中触觉带来 2.2–15.6 个百分点成功率提升【自报】。[arXiv:2608.16572](https://arxiv.org/abs/2608.16572)
- **2026-08-13｜DreamX-Phi 1.0 机器人视频世界模型**：由首帧、指令和双臂动作预测未来观测，引入 SE(3) 编码、深度分支和 V-JEPA 蒸馏；WorldArena 2.0 两赛道分列第一、第二【自报】。[arXiv:2608.13489](https://arxiv.org/abs/2608.13489)
- **2026-08-12｜G0.5 统一自回归推理与动作**：同一解码器交错生成推理和动作 token，并用跨本体动作 tokenizer 与视觉记忆支持多机器人；报告 LIBERO 98.9%、RoboTwin 2.0 93.3%【自报】。[arXiv:2608.11739](https://arxiv.org/abs/2608.11739)
- **2026-08-13｜X Square Robot 物流演示**：Quanta X2、Wall-OSS 世界模型与 VLA 完成拣选、搬运和分拣；无独立真机 benchmark，能力描述均为【自报】。[公司新闻稿](https://www.prnewswire.com/apac/news-releases/x-square-robot-demonstrates-embodied-ai-in-real-world-logistics-operations-302850581.html)

### ⚠️ 传闻

- **2026-08-17｜“宇树 Superman 超高速人形机器人”视频**：社区广泛转载，但未找到宇树官方产品页、技术报告或可核验测试条件。

### 本周最值得关注的 2–3 项

1. τ₀-VLA 把测试时计算推进到长程机器人子任务选择。
2. G0.5 用单一自回归流统一推理与动作。
3. ViHaTeleop 给出低成本触觉遥操作的真机验证链路。

## 第二路｜多模态大模型

### ✅ 已核实要点

- **2026-08-15｜MOSS-VL 开源实时交互 VLM 家族**：通过门控交叉注意力边看边说，并公开 5 个 checkpoint、训练课程和实时推理代码；11.3B 模型长视觉上下文 TTFT 优势由 2.8× 扩至 5.1×【自报】。[arXiv:2608.15045](https://arxiv.org/abs/2608.15045)
- **2026-08-14｜Qwen3.8-27B 官方权重开放**：官方 Hugging Face 仓库上线 Apache-2.0 权重，任务类型为 `image-text-to-text`。[官方模型卡](https://huggingface.co/Qwen/Qwen3.8-27B)
- **2026-08-13｜EgoMonth 月级第一视角视频 benchmark**：包含 20 人、跨 20–120 天的 300+ 小时录像与 1,443 组人工问答；最佳模型仍比人工基线低 22.4 个百分点【自报】。[arXiv:2608.13113](https://arxiv.org/abs/2608.13113)
- **2026-08-13｜NaviDC-OCR 文档解析**：加入形变感知、自适应采样及内容—结构解耦训练；三个 benchmark 分数为 96.87 / 88.53 / 78.41【自报】。[arXiv:2608.12898](https://arxiv.org/abs/2608.12898)
- **2026-08-12｜StrAD 长视频流式音频描述**：不依赖真值时间戳，以滑动窗口处理完整视频并在语音间隙生成描述【自报】。[arXiv:2608.12549](https://arxiv.org/abs/2608.12549)

### ⚠️ 传闻

- 本周未发现值得单列、且有可信二手交叉信源的新模型传闻。

### 本周最值得关注的 2–3 项

1. MOSS-VL 主打“持续看、适时说、必要时修正”的实时交互栈。
2. EgoMonth 将长视频评测推进到跨数周连续生活记忆。
3. OCR 与视频理解均在走向复杂实拍和持续流式输入。

## 第三路｜部署 / 推理 Infra

- **2026-08-10｜vLLM v0.27.0**：561 个提交、242 位贡献者【自报】；支持 Kimi K3，并升级 PyTorch 2.13、Triton 3.7.1。[GitHub Release](https://github.com/vllm-project/vllm/releases/tag/v0.27.0)
- **2026-08-10｜vLLM 长上下文与分离式推理**：FA4 在 SM100 增加 FP8 KV cache/head-dim 256；新增混合 MLA+SSM NIXL P/D、异构 block size、MoRIIO 路由及 P2P KV 二级缓存。[GitHub Release](https://github.com/vllm-project/vllm/releases/tag/v0.27.0)
- **2026-08-10｜vLLM 集群容错与 Rust 前端**：加入 DP+EP 容错、弹性 EP 异步准备，以及健康检查、请求终止、服务发现等 gRPC 控制面能力。[GitHub Release](https://github.com/vllm-project/vllm/releases/tag/v0.27.0)
- **2026-08-11｜vLLM v0.27.1**：增加量化 DSpark Markov head 支持。[GitHub Release](https://github.com/vllm-project/vllm/releases/tag/v0.27.1)
- **2026-08-12｜TensorRT-LLM v1.3.0rc24**：加入 TriAttention KV-cache 压缩、FlashInfer block reuse、Kimi K3/KDA kernel 等；官方同时列出若干已知崩溃风险。[GitHub Release](https://github.com/NVIDIA/TensorRT-LLM/releases/tag/v1.3.0rc24)

### ⚠️ 传闻

2. Rust 前端开始具备独立控制面能力。

## 第四路｜轻量化 / 模型压缩

### ✅ 已核实要点

- **2026-08-16｜FluxBin 超低比特算法—内核协同**：行列二进制分解配合 LUT CUDA kernel；最高 5.92× 加速、10.19× 能耗下降及单 A100 部署 70B【自报】，代码已公开。[arXiv:2608.15602](https://arxiv.org/abs/2608.15602)
- **2026-08-16｜SchurQuant 2–3 bit 权重量化**：通过 Schur 补曲率做组级离散优化；8 个 Llama/Qwen 模型上，2-bit 平均零样本准确率较最佳对照高 9.65 个百分点【自报】。[arXiv:2608.15567](https://arxiv.org/abs/2608.15567)
- **2026-08-16｜FlashQuant 融合 W4A16 与稀疏异常值计算**：单 kernel 融合低比特 GEMM 和高精度 SpMM；较 cuBLAS BF16 加速 2.74–4.18×【自报】。[arXiv:2608.15531](https://arxiv.org/abs/2608.15531)
- **2026-08-14｜QUASAR 量化感知训练**：训练中持续做轻量损失感知重建，兼容整数与 NVFP4；2-bit 八任务平均准确率提升 3.5–4.3 个百分点【自报】。[arXiv:2608.13966](https://arxiv.org/abs/2608.13966)

### ⚠️ 传闻

- **2026-08-17｜TensorShrink 社区项目**：作者称 2/4/6/8-bit 量化优于 bitsandbytes，但缺少论文与独立复现。

### 本周最值得关注的 2–3 项

1. FluxBin 与 FlashQuant 都把压缩算法和 CUDA 执行路径绑在一起验证。
2. SchurQuant 显示 2-bit PTQ 仍有较大算法空间。
3. QUASAR 聚焦 QAT 的训练—重建错配，同时保持标准部署格式。

## 第五路｜训练进展

### ✅ 已核实要点

- **2026-08-17｜Le Critique：LLM RL 的特权价值函数**：PVF 注入额外 token 级信号，TETHER 按价值函数准确度在组相对与价值基线间插值；多个任务匹配或超过均值基线 GRPO【自报】。[arXiv:2608.16739](https://arxiv.org/abs/2608.16739)
- **2026-08-14｜Rollplex：VLM 后训练跨阶段 GPU 共享**：将 reference/training 前缀计算移入 rollout 解码窗口，并做显存管理和跨 TP 权重共享；32 张 H800 上较串行共置提速 1.23–1.30×【自报】。[arXiv:2608.14498](https://arxiv.org/abs/2608.14498)
- **2026-08-14｜领域数据重复的预训练 scaling 研究**：固定 tokens-per-parameter 时，最优重复次数随模型规模温和增加，并与领域最终验证损失强负相关【自报】。[arXiv:2608.14071](https://arxiv.org/abs/2608.14071)
- **2026-08-11｜MISA-T 混合 RL rollout 调度**：面向 RLVR、RLHF 与 agent rollout 共用服务，联合做会话准入、KV 分配和驻留时间记账；吞吐提升 35.6%、平均迭代时间下降 22.8%【自报】。[arXiv:2608.11152](https://arxiv.org/abs/2608.11152)

### ⚠️ 传闻

- 本周无值得单列的训练方法或训练系统传闻。

### 本周最值得关注的 2–3 项

1. Rollplex 与 MISA-T 都在解决 RL 后训练中的 GPU/KV 资源争用。
2. Le Critique 重新评估带 critic 的 token 级信用分配。
3. 领域数据重复研究提供了可迁移的 proxy-model 调参思路。
