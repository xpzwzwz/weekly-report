## 第五路 — 训练进展（怎么训）

### ✅ 已核实要点

**1. VIGOR：方差引导渐进式 Rollout 分配改进 GRPO（arXiv:2607.22002，2026-07-24）**
核心洞察：RLVR 中奖励方差控制梯度幅度，对高方差样本动态增加 rollout 最高效。数学推理减少最高 2.3x rollout、编程任务减少 1.49x rollout 且 pass rate +3.4pp【自报】。
[arxiv.org/abs/2607.22002](https://arxiv.org/abs/2607.22002)

**2. ESTR：异步 RL 的熵缩放信任域（arXiv:2607.22186，2026-07-24）**
发现异步 GRPO 中 importance ratio 与 token 熵系统性相关，ESTR 用局部熵自适应调整 off-policy 偏差无需额外前向传播，同等精度下训练速度 2.6x 于同步 GRPO【自报】。
[arxiv.org/abs/2607.22186](https://arxiv.org/abs/2607.22186)

**3. Distilled RL：教师监督嵌入 RL 目标（arXiv:2607.17247，2026-07-19）**
将教师信号以 token 级策略梯度形式注入，含反向重要性采样裁剪、负样本重置、几何归一化。同族与跨族蒸馏均超越标准 RL 和 on-policy 蒸馏（OPD）【自报】。
[arxiv.org/abs/2607.17247](https://arxiv.org/abs/2607.17247)

**4. 理解从预训练到后训练的推理能力（arXiv:2607.16097，2026-07-17）**
NYU/Apple 以国际象棋为受控环境（5M–1B 参数，预训练→SFT→RL 完整管线）。核心结论：**给定 RL 算力下的后训练性能由预训练 loss 准确预测**；RL 奖励提升与预训练 token 数近似线性正比。在数学任务上验证。
